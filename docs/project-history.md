when work happened, not when Git commits were created. Exact daily changes
were not recorded in Git and are not reconstructed here.

| Date | Milestone |
| --- | --- |
| 2026-08-01 | Work on the Kafka backtest project began. |
| 2026-09-18 | Final variant of the pre-Git work period. |
| 2026-11-11 | The existing project was first committed to Git and published. |
| 2026-11-15 | The native segment-reader slice was added and committed. |

The August–September dates describe the author's work period. The November
dates are verifiable from the repository's Git history. This distinction avoids
presenting retrospective milestones as original commits.
